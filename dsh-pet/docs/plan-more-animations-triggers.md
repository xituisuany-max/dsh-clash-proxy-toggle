1. **动画库从 7 个扩到 12–14 个**：覆盖更多情绪与场景（吃、跳舞、生气、害羞、惊吓、伸懒腰、唱歌、游泳…）

## 4. 新触发方式清单

### 4.1 鼠标手势（代码层即可实现，P1 落地，用现有动作验收）

| 触发 | 行为 | 备注 |
|---|---|---|
| **长按 600ms** | 摸摸头：happy/blush + 「呜…好舒服~」 | 需区分单击（已有 260ms 延迟机制可扩展） |
| **悬停 1.5s** | 小概率 wave + 「嗯？主人在看鲸鱼娘~」 | 防抖：同一位置只触发一次，移开再回才重置 |
| **右键** | 弹出上下文菜单：动作点播（全部动作）、设置（大小/透明度/台词开关）、重置位置、隐藏 | 菜单为独立浮层，主题自适应 |

| **滚轮** | 桌宠放大/缩小（80%–150%） | 可选，低优先；也可做"被戳"反应 |

### 4.2 时间型触发（P1/P3）

| 触发 | 行为 |
|---|---|
| **整点报时** | 每小时整点气泡「现在 X 点啦~」（可开关） |
| **时段问候** | 首次交互按 早/午/晚/深夜 选台词：早上好/下午好/晚上好/熬夜冠军… |
| **深夜提醒** | 23:00–6:00 每天一次「夜深了，主人早点休息哦~」+ 小概率 sleep |
| **空闲分级** | 90s → sleep；5min 无操作 → 气泡换「呼…呼…」（不重复刷屏） |

### 4.3 状态型增强（P3，扩展现有会话联动）

| 触发 | 行为 |
|---|---|
| 任务开始瞬间 | surprise（第一批）或 think + 「开工啦！」 |
| 审批等待 | wait 动作（第三批） |
| 同一 turn 连续 2 次错误 | angry（第二批） |
| 长任务运行中（>60s） | 从 think 平滑过渡到 wait/stretch 小动作 |
| 页面从隐藏恢复 | surprise 小概率 + 「欢迎回来~」 |
| **关键词触发（待验证）** | 若 session 快照含用户消息文本：说「睡觉/跳舞/唱歌/吃饭/辛苦/摸摸」→ 对应动作。**可行性需先验证**，不行则降级为纯状态触发 |

### 4.4 随机小动作（P1）

- 空闲且无状态动作时，每 40–90s 随机播一个短动作：stretch / blush / think 一瞬 / wave 小挥手
- 不打断：用户主动动作、sleep、状态动作；优先级最低

## 5. 技术改造方案

### 5.1 动作管理器重构（核心，P1）

现状问题：`playAction()` 直接抢断，状态动作（think/cry）和用户动作互相覆盖，无恢复逻辑。

```
ACTIONS 注册表扩展：
  { action, fps, loop, priority, triggerSource, frames: dir }

优先级（数字小者先，同优先级后到者胜）：
  0  用户主动（单击/长按/双击/右键点播/拖拽）
  1  会话状态（think/cry/happy/wait/surprise）
  2  时间型（整点/问候/深夜提醒）
  3  随机小动作

打断规则：
  - 新动作优先级 < 当前 → 忽略（如随机小动作不打断 think）
  - 新动作优先级 > 当前 → 打断，记下被中断的"状态动作"
  - 用户动作播完 → 若期间有状态动作被中断且仍在运行 → 恢复该状态动作；否则回 idle
  - sleep 例外：仅用户动作/唤醒可打断
```

### 5.2 台词库分场景（P1）

`LINES` 平铺数组 → `LINES_BY_SCENE`：

```
{ click, longpress, hover, fling, error, done, start, wake,
  idle, sleep, hourly, greeting_morning/afternoon/evening/night,
  night_remind, menu_open, ... }
```

每条台词可带 emoji；保留随机选择；台词开关可持久化。

### 5.3 轻量粒子特效（P1）

纯 DOM/CSS 粒子（无新依赖），跟随动作释放，动作结束自动清理：

| 动作 | 粒子 |
|---|---|
| happy / dance | 心形 / 音符 |
| cry | 泪滴 |
| sleep | Zzz |
| swim | 泡泡 |
| blush | 脸红标记（`>///<`） |

### 5.4 偏好持久化（P1）

`localStorage`（key：`dshPetPrefs`）：位置、大小（80–150%）、透明度、台词开关、动作开关、双击循环位置、整点报时开关。桥接重启/页面刷新后恢复。

### 5.5 右键菜单 + 设置浮层（P1）

- 动作点播：一键播放任意已生成动作（含新动作）
- 设置：大小滑杆、透明度滑杆、台词开关、整点开关、重置位置、隐藏桌宠
- 复用气泡的 CSS 变量实现主题自适应；菜单点击外部自动关闭

### 5.6 素材接入（P2）

- 新动作帧放 `outputs/imagegen/pet/<action>_0/`，桥接零改动
- 引擎已支持目录自动探测（`<action>_0` → `<action>`），新动作只需在 ACTIONS 注册表加一行

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| Ref2VA 新动作角色一致性漂移 | 固定参考图 + 首帧贴 idle 姿态；每批先出 1 个验证再批量 |
| 蓝发/鱼尾绿幕抠图边缘残留 | 现有抠图管线加边缘羽化/去色边；必要时逐帧检查 |
| 动作互相打断混乱 | P1 优先级队列先落地，现有动作即可回归验证 |
| 关键词触发依赖 session 快照含消息文本 | P3 先做 10 分钟可行性验证；不可行则砍掉该触发，其余不受影响 |
| 帧体积膨胀（每动作 ~41 帧 PNG） | 220×220 单帧 ~15–30KB，单动作 <1.5MB，可接受；若超限备选 WebP 序列（需小改引擎） |
| 触发太频繁打扰用户 | 所有时间型/随机触发带开关与冷却；默认保守频率 |
